# Testing Instructions

You can verify the system workflows using the UI at `http://localhost:5173` or by testing the core python modules using the CLI.

- **Intake:** Register a new file.
- **Hash verification:** Upload an original file to Verify and see MATCH.
- **Tamper detection:** Modify the file and upload to Verify and see MISMATCH.
- **Custody chain:** Add events in the UI and view the Custody Chronicle.
