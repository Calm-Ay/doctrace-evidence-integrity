# Demo Walkthrough

1. Start Doctrace using SETUP.md
2. Open dashboard at `http://localhost:5173`
3. Intake sample evidence (use `sample_data/demo_evidence.txt`)
4. Show generated Evidence ID and SHA-256 Hash
5. Show COLLECTED event in Evidence Detail
6. Add TRANSFERRED event using 'Log Action'
7. Verify evidence by uploading original file -> Show MATCH
8. Modify the local copy slightly
9. Verify again -> Show MISMATCH
10. Generate court report from Evidence Detail view
